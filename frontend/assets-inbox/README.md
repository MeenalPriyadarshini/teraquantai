# assets-inbox: drop ORIGINAL images here

1. Put the original in the matching subfolder, with the same naming rule as `public/images/README.md`
   e.g. `assets-inbox/products/maize-market-forecast-sangli.png`
2. Run `npm run images`
3. The optimised `.webp` (max 1600px wide, ~80% quality) appears in `public/images/products/`

Originals stay here and are never served by the website.
