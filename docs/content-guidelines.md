# Content & claims rules (from roadmap §3, §11, §12)

**Do**
- Describe the product as a forecast / report / intelligence deliverable.
- Show on every product: market, location, period, unit, frequency, scenarios, exact deliverables, price, limitations.
- Label forecasts as estimates with the date range and unit (e.g. ₹/qtl).
- Mark all sample prices, purchases and metrics as placeholders until approved.

**Don't**
- Say customers buy or download an AI model, code or weights.
- Publish accuracy percentages, algorithm names, training-data claims or "proprietary model" claims without proof.
- Imply real-time data, live monitoring, personalisation or auto-updates unless true.
- Guarantee prices, profits or outcomes.
- Promise Excel/dataset/tool downloads that are not confirmed deliverables.
- Mix mandi/variety references (Sangli/Miraj ≠ Tasgaon).
